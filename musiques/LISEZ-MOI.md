# Bibliothèque musicale de l'équipe

Les musiques déposées ici apparaissent automatiquement dans le Studio Vidéo
(section « Ma musique » → « Bibliothèque de l'équipe ») pour tous les collaborateurs.

1. Choisir des musiques **libres de droits pour un usage commercial** (ex. Pixabay Music, licence Pixabay).
2. Déposer les fichiers `.mp3` dans ce dossier.
3. Les déclarer dans `musiques.json` :

```json
[
  { "file": "acoustique-lumineuse.mp3", "name": "Acoustique lumineuse", "mood": "Calme · maison familiale" },
  { "file": "piano-elegant.mp3", "name": "Piano élégant", "mood": "Haut de gamme" }
]
```
